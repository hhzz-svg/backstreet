# 暗巷 BACKSTREET

一条昏暗的巷子,一把 AR-15,几个会朝你还击的敌人。

这是个巷战射击 demo,核心就一件事:枪打起来到底爽不爽。

## 特点

- **打枪手感是重点**。开火有后坐力和枪口火光,打中会有屏幕震动、短暂的定帧顿感、命中提示音,打死人还会有一小段慢镜头。
- **枪声是真的分层合成的**,不是放一个音效文件,所以听起来每次开火都有细节上的差别。
- **打在不同材质上效果不一样**:混凝土墙、铁皮、木板、玻璃,弹孔和火花都不同,有些材质子弹能穿过去。
- **右键开镜**,默认是按一下开、再按一下关,不用一直按着。
- 整个游戏没有用任何下载的图片、模型或音效素材,墙面纹理、枪声、特效全是代码生成出来的。
- 打开设置面板可以把"打击感"总开关关掉再打开做对比,一眼就能看出差别有多大。

## 怎么玩

浏览器打开就能玩,不需要装任何东西。

| 键 | 作用 |
|---|---|
| WASD | 移动 |
| Shift | 冲刺 |
| Ctrl | 蹲下 |
| 空格 | 跳跃 |
| Q / E | 探头(靠墙角看两边很有用) |
| 鼠标左键 | 开火 |
| 鼠标右键 | 开镜 / 收镜 |
| R | 换弹 |
| K | 打击感总开关(体验一下有和没有的区别) |
| F | 切换画质 |
| P | 调参面板 |
| Esc | 松开鼠标 |

## 自己跑起来

需要装 [Node.js](https://nodejs.org/)。

```bash
npm install
npm run dev
```

然后浏览器打开 `http://127.0.0.1:5173`,点一下开始界面就能进游戏(第一次进去会有几秒钟的加载,是在后台把画面需要的东西准备好)。
