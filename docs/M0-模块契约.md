# M0 模块契约

> 所有并行实现的模块必须严格按此文件导出。不要改动别人的文件，只写自己负责的文件。
> 共享基础设施已存在，**直接 import，不要重写**：
> - `src/core/time.ts` — `time`（双时钟）、`setUnscaledTimeout`、`expApproach`、`lerp`、`clamp`、`clamp01`
> - `src/core/noise.ts` — `noiseSigned`、`fbmSigned`、`randInDisk`、`randSigned`、`mulberry32`
> - `src/types.ts` — `SurfaceKind`、`SurfaceDef`、`HitInfo`、`EnemyRef`、`BodyPart`、`DamageResult`、`WeaponDef`
> - `src/feel/config.ts` — `feelConfig`、`feelOn(layer)`、`frames(n)`
> - `src/level/materials.ts` — `SURFACES`、`surfaceOf(kind)`、`PART_MULTIPLIER`
> - `src/weapons/defs.ts` — `AR15`、`fireInterval(w)`、`falloffMul(w, dist)`

## 铁律

1. **双时钟**：粒子 / 相机震动 / 后处理 / UI / 音频一律用 `time.unscaledDelta`；角色移动 / AI / 动画用 `time.scaledDelta`。在每个 `update(dt)` 的注释里写明你用的是哪个。
2. **定时器**只用 `setUnscaledTimeout`，禁止 `setTimeout`。
3. **参数**从 `feelConfig` 读，不要在自己文件里写死打击感数值。
4. **池化**：伤害数字、贴花、粒子、动态光源必须预分配复用，禁止运行时 `new` 网格。
5. **零外部资源**：不下载任何贴图/模型/音频，全部程序化生成（Canvas 画贴图，WebAudio 合成音效，代码生成几何）。
6. TypeScript strict 模式必须通过 `npx tsc --noEmit`。
7. 只用已安装的依赖：`three`、`three-mesh-bvh`、`postprocessing`、`lil-gui`。**不要用 `three.quarks`**（M0 自己写粒子池，见下）。

## A · `src/feel/trauma.ts` `hitstop.ts` `recoil.ts` `rumble.ts`

```ts
// trauma.ts
export interface ShakeOffset { pitch: number; yaw: number; roll: number }
export class TraumaShake {
  /** distance/falloffRadius 都给时按 1/(1+d²/r²) 衰减（爆炸用） */
  add(amount: number, distance?: number, falloffRadius?: number): void;
  /** dt 用 unscaledDelta；elapsed 用 time.elapsed */
  update(dt: number, elapsed: number): ShakeOffset;
  get value(): number;
  reset(): void;
}
export const shake: TraumaShake;   // 单例

// hitstop.ts —— 直接改 time.timeScale，用 setUnscaledTimeout 恢复
export function hitStop(frameCount: number): void;
/** 击杀慢镜：timeScale→slowmo.scale，durationMs 后用 recoverMs 缓动回 1 */
export function killSlowMo(): void;
/** 每帧调用，驱动慢镜缓动恢复 */
export function updateTimeControl(dtUnscaled: number): void;
export function resetTimeControl(): void;

// recoil.ts
export class Recoil {
  kick(w: WeaponDef): void;
  /** dt 用 unscaledDelta */
  update(dt: number): void;
  readonly pitch: number;   // 弧度，加到相机 rotation.x
  readonly yaw: number;     // 弧度，加到相机 rotation.y
  readonly kickZ: number;   // 米，枪模后缩
  /** 连发累积的枪口上抬，射击停止后缓动归零 */
  readonly climb: number;
  reset(): void;
}

// rumble.ts
export function rumble(strong: number, weak: number, ms: number): void;  // 0..1
export function hasGamepad(): boolean;
```

要求：
- trauma 幅度 = `t ** feelConfig.shake.exponent`，用 `noiseSigned` 三个不同 seed 分轴驱动，频率 `feelConfig.shake.freq`。
- `hitStop` 必须尊重 `feelOn(feelConfig.hitstop.enabled)`；关掉时直接 return。
- 重入安全：定帧期间再次命中，取较长的那个，不要叠加成永久冻结。

要求：
- hitscan 用 `three-mesh-bvh` 的 `acceleratedRaycast` + `raycaster.firstHitOnly = true`。
- 散布：`randInDisk()` 在锥内采样，按站/走/ADS/空中切换半角。
- **穿透**：击中 `penetration > 0` 的表面时继续射线，伤害乘以穿透系数，最多 `maxPenetrations` 层。
- 伤害 = `damage × PART_MULTIPLIER × falloffMul × 穿透衰减`，护甲 >0 时 ×0.6。
- 枪模：程序化几何（枪身/枪管/弹匣/枪托/瞄具），**摇摆 sway**（跟随鼠标增量反向偏移再弹回）、**bob**（移动时正弦）、**后坐**（recoilKick 后缩 + climb 上抬）、ADS 时移到屏幕中心并关闭 bob。
